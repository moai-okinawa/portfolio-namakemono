---
name: add-portfolio-project
description: ナマケモノポートフォリオの作品一覧に作品を1件追加し、表示確認からコミットとプッシュまで行う。作品を新しく掲載したいときに使う。
---

1. ユーザーに作品名、掲載する説明、作品の公開URLをまとめて聞く。依頼に含まれている項目は聞き直さず、不足分の返答を待ってから編集する。
2. 対象が `moai-okinawa/portfolio-namakemono` であることを確認し、`git status` で既存の作業を確認する。リポジトリ直下の `Design.md` と `index.html` の作品一覧を読む。
3. `index.html` の `.works-grid` の末尾にカードを1件追加する。既存の公開作品カードを参考に `.work`、`.work-media`、`.work-body`、`.work-copy`、`.pill` を使い、固有のIDと対応する見出しを付ける。公開状態は確認できた情報に合わせる。提供されたスクリーンショットがあれば `assets/` に保存し、代替テキストを付けて縦横比を保つ。画像がなければ既存のスクリーンショット枠を使う。既存カードとロイ、SNSリンク、公開設定、アプリ本体には手を加えない。
4. ローカルでPCとスマホ幅の表示、新しい作品リンク、既存カードの並びを確認する。差分に対象作品の変更だけが含まれることを確認する。
5. 今回のファイルだけをコミットし、指定されたブランチへプッシュする。指定がなければポートフォリオの `origin/main` に最新のリモート履歴を土台として反映する。ローカルのみなど依頼時の公開条件があればそれに従う。強制プッシュは使わない。
6. 表示とリンクの確認結果、プッシュ先、コミットを報告する。GitHub Pagesの公開を伴う場合は反映を確認し、公開URLも伝える。
